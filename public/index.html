1. Dashboard-Aufbau, Grid-Layout & Konkrete Panel-Typen

Zeile 1 · Executive Summary y=0, h=4 (4 Panels à w=6 auf 24er-Grid)

Panel-Typ: Grafana Stat Panel (Big Value, Color Mode: Background Solid oder Value, Sparkline: Disabled)

Betriebsziel: In < 1 Sekunde aus 3 Metern Entfernung erkennbar: 18/18 Dienste, 5/5 Hosts, 42/42 Container, SSL OK.

Zeile 2 · Kritische Dienste y=4, h=4 (6 Panels à w=4 oder 1 State-Matrix-Panel w=24)

Panel-Typ: Stat Panel / State Timeline (Current Value Only) / Status History

Betriebsziel: Binäre Farblogik ohne Zwischenfarben: Grün (#10B981) = Online (1), Rot (#EF4444) = Offline (0) für Vaultwarden, Immich, Home Assistant, Gitea, Traefik, WireGuard.

Zeile 3 · Infrastrukturzustand y=8, h=5 (3 Gauge/Stat-Panels à w=6 + 1 Netzwerk-Panel w=6)

Panel-Typ: Gauge Panel (oder Bar Gauge) für CPU/RAM/Disk + Time Series Sparkline (letzte 15 Min.) für Netzwerk

Betriebsziel: Sofortige Engpass-Erkennung nach strengen Schwellwerten (CPU 70/85 %, RAM 75/90 %, Disk 80/90 %).

Zeile 4 · Container-Gesundheit (Dazzle) y=13, h=4 (3 Stat-Kacheln à w=4 + 1 kompakte Bar-Gauge/Table w=12)

Panel-Typ: Stat Panel (Healthy=42, Unhealthy=0, Restarts 24h=3) + Bar Gauge / Kompakt-Tabelle (Top Restarts)

Betriebsziel: Crash-Loops (z. B. Jellyfin x3, Immich x1) erkennen, bevor ein Dienst komplett ausfällt.

Zeile 5 · Warnungen / Incidents y=17, h=4 (Volle Breite w=24, max. 5 Einträge)

Panel-Typ: Alert List Panel (Grafana Unified Alerting) oder Table Panel (Transform: Limit 5, Sort by Severity)

Betriebsziel: Maximal 5 priorisierte Vorfälle (Rot = Kritisch, Gelb = Warnung, Blau/Grau = Information) ohne Scrollbalken.

2. Verbindliches NOC-Farbschema (3-Meter-Lesbarkeit)

Warnung / Degraded
#F59E0B

CPU 70–85 %, RAM 75–90 %, Disk 80–90 %, Container-Restarts > 0 (24h), SSL-Ablauf < 21 Tage.

#38BDF8

count(monitor_status{job="uptime-kuma"})

3. SSL-Zertifikate Status & kürzeste Restlaufzeit in Tagen Uptime Kuma

Stat Panel · Value Mapping: >= 14 → OK (Grün), 7..14 → WARNUNG (Gelb), < 7 → KRITISCH (Rot)

min(monitor_cert_days_remaining{job="uptime-kuma"})
4. Hosts Online (Beszel / Node Exporter Heartbeat) Beszel / Prometheus

Stat Panel (Anzeige: 5 / 5)

count(up{job=~"beszel|node-exporter"} == 1)
/
count(up{job=~"beszel|node-exporter"})
5. CPU-Auslastung in % (Schwellwerte: < 70 % Grün, 70–85 % Gelb, > 85 % Rot) Node Exporter

Gauge / Stat Panel

100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle", instance="192.168.178.90:9100"}[2m])) * 100)
6. Arbeitsspeicher (RAM) in % (Schwellwerte: < 75 % Grün, 75–90 % Gelb, > 90 % Rot) Node Exporter

Gauge / Stat Panel

(1 - (node_memory_MemAvailable_bytes{instance="192.168.178.90:9100"} / node_memory_MemTotal_bytes{instance="192.168.178.90:9100"})) * 100
7. Datenträger-Belegung Root-FS in % (Schwellwerte: < 80 % Grün, 80–90 % Gelb, > 90 % Rot) Node Exporter

Gauge / Stat Panel

100 - ((node_filesystem_avail_bytes{mountpoint="/", fstype!~"tmpfs|overlay"} / node_filesystem_size_bytes{mountpoint="/", fstype!~"tmpfs|overlay"}) * 100)
8. Netzwerk Inbound / Outbound (Bit/s) Node Exporter

Stat + Mini-Sparkline (Zeitfenster: letzte 15 Minuten)

# Inbound (Receive):
rate(node_network_receive_bytes_total{device=~"eth0|eno1|ens18"}[2m]) * 8
# Outbound (Transmit):
rate(node_network_transmit_bytes_total{device=~"eth0|eno1|ens18"}[2m]) * 8
9. Container Healthy, Unhealthy & Top-Restarts (letzte 24h) Dazzle / cAdvisor / Docker Exporter

Stat Panels + Bar Gauge (Top 5 Restarts)

# Healthy Container:
count(container_health_status{status="healthy"} == 1)
# Unhealthy Container:
count(container_health_status{status="unhealthy"} == 1)
# Container Restarts (letzte 24h, Top-Liste):
topk(5, round(increase(container_start_time_seconds{name!=""}[24h]) > 0))

4. Grafana-Plugins & Android-Tablet-Kiosk-Optimierungen

100 % Native Grafana Core Panels (Empfohlen) Core (Grafana 10 / 11)

Stat, Gauge, Bar Gauge, State Timeline und Alert List decken alle 5 Zeilen ohne externe Plugin-Abhängigkeiten ab — extrem schnell auf ARM-Tablets und wartungsfrei bei Grafana-Updates.

Polystat Panel (grafana-polystat-panel) Optional · Signiertes Community-Plugin

Ideal, falls Zeile 2 (Kritische Dienste) später auf 12+ Dienste als Waben-Matrix mit Auto-Scaling erweitert werden soll.

Infinity Datasource (yesoreyeram-infinity-datasource) Optional · JSON/REST-Brücke

Ermöglicht das direkte Abfragen von REST-JSON-Endpunkten aus Beszel, Dazzle oder Portainer API, falls einzelne Metriken noch nicht in Prometheus gescraped werden.

Grafana TV/Kiosk-URL & Auto-Refresh 8–10" Tablet Kiosk

URL auf dem Tablet mit ?kiosk&refresh=10s&theme=dark&from=now-15m&to=now öffnen. Blendet Seitenleiste, Header und Zeitwähler komplett aus und begrenzt die Query-Last auf die letzten 15 Minuten.

Fully Kiosk Browser (Android 8–10 Zoll) 8–10" Tablet Kiosk

Keep Screen On aktivieren, Status-/Navigationsleiste ausblenden, Auto-Reload bei Netzwerkverlust einschalten und Bewegungserkennung per Frontkamera (Motion Detection) für nachts nutzen.

3-Meter-Lesbarkeit & Typografie 8–10" Tablet Kiosk

Executive-Summary-Werte mit mindestens 38–52 px Schriftgröße (Big Shoulders Display 900), klare Kontrastkanten und Verzicht auf kleine Achsenbeschriftungen.

AMOLED Burn-In-Schutz 8–10" Tablet Kiosk
